# Referencje i inspiracje

- [Awesome Opus 5.5 Videos](https://github.com/yihui-dev/awesome-opus5-5-videos): lokalnie `../tools/repos/awesome-opus5-5-videos/`. Punkty wejścia: `README.md`, `prompts/`, `data/videos.json`. To zbiór promptów i linków do prac autorów; filmy pod linkami nie zostały pobrane ani obejrzane w ramach kolekcjonowania źródeł.
- Przykłady Hypermotion: pliki `.hype` i dokumentacja w `../tools/repos/hypermotion/`.
- Claude Motion: `examples/`, `sims/` i wspólna oś czasu w `../tools/repos/claude-motion/`.
- Howseen: źródła filmu w `../tools/repos/claude-motion-design/examples/howseen-launch/`. Muzyka i inne media pobierane przez jego skrypt nie są częścią naszego pobrania.
- Motion Anything: `recipes/` zawiera lokalne przykłady animacji; OpenDesign ma osobny katalog `design-templates/`.

Przy wyborze inspiracji zapisujemy konkretny przykład, co z niego bierzemy (np. rytm, sposób wejścia tekstu, kadr) oraz oryginalnego autora. Nie traktujemy cudzych materiałów i muzyki jako własnych zasobów.
