# Security

Report vulnerabilities through GitHub private vulnerability reporting when available. Do not put secrets or client material in public issues.
Treat HTML compositions as executable code. Render trusted local files only, in an isolated environment for untrusted contributions.
Job references are confined to the job directory. Asset imports are explicit. Output files are not published automatically.
The release scanner is a defense in depth check, not proof that arbitrary files are safe to publish.
Rotate accidentally disclosed credentials and remove them from history before publication.
