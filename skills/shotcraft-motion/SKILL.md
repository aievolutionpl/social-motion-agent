# ShotCraft Motion Pack

Read [the complete integration guide](../../docs/SHOTCRAFT_MOTION_PACK.md), then the existing [Creative Director](../creative-director/SKILL.md) and feedback-loop rules. This is an optional shot-selection layer, not a replacement for the main workflow or a separately installed rendering engine.

Use the guide's curated upstream links to inspect the exact recipe and corresponding demo before implementing a close match. Prefer adapting the motion principle to the existing renderer; isolate Remotion-specific code if needed. Always propose directions before substantial production unless the user has already selected or delegated a direction.

For every output: brief → direction → storyboard → representative preview → actual render inspection → timestamped feedback → revised export and QA. Report unsupported capabilities and missing assets. Never claim the listed effects are already executable local presets solely because this reference skill exists.
