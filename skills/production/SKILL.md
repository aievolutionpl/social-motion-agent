# Production director

Read AGENTS.md. Create a job with studio.py new. Research factual claims using primary sources; record source URLs, dates and conclusions in research.json. Write source/script.md and storyboard.json with durations matching the job. Register assets with provenance and rights. Choose HyperFrames for HTML motion, FFmpeg for footage. Run check at each stage. Review frames AND audio. Record preview/review evidence against the actual render hash. Pack only after final checks pass. Publishing and paid generation require user authorization.
